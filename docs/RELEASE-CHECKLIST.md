# Release checklist

Names and sources only. No values here, and no secrets anywhere in this repo.

## A. Owner supplies

| Item | Source | Goes in |
|---|---|---|
| Meta Pixel ID | Meta Events Manager | `TRACKING.metaPixelId` in `assets/js/config.js` (public ID, not a secret) |
| GTM container ID | Google Tag Manager | `TRACKING.gtmContainerId` in `assets/js/config.js` (public ID, not a secret) |
| Official URL `https://edgecoursebd.com/admission26/` (already set). Backup for SMS until launch: `https://hulkenstein.com/admission26/` | Owner | `canonical`, `og:url`, `og:image`, `twitter:image` in `index.html`; path prefix in `_headers` |
| Privacy policy URL | Owner | footer link in `index.html`; confirm it covers the Pixel |

## B. Generated by the release owner

`CLOUDFLARE_API_TOKEN` in `.env.cloudflare` (git-ignored): the owner creates it in Cloudflare (My Profile → API Tokens, "Edit Cloudflare Workers" template, zone hulkenstein.com only). The page itself holds no keys. The Vercel preview login stays in the owner's account.

## C. Settings that need a specific value

| Setting | File | Required |
|---|---|---|
| `OFFER.endsAt` | `assets/js/config.js` | The campaign deadline, ISO time with `+06:00` |
| `OFFER.couponCode` | `assets/js/config.js` | The code the shop accepts |
| `OFFER.courses.percent`, `OFFER.books.percent`, `OFFER.books.upTo` | `assets/js/config.js` | Match the offer the shop honours |
| `<title>`, meta description, `og:description`, `twitter:description` | `index.html` | Same offer text. `node --test` fails on drift |
| `canonical`, `og:url` | `index.html` | The final public URL |
| `assets/img/og-cover.jpg` | `assets/img/` | Redrawn with `python scripts/make-image.py og` after any offer change |
| Pixel and GTM IDs | `assets/js/config.js` | Empty (off) or valid; if a new tag host is added, update the CSP in all copies |

## D. Dashboard settings

See `docs/SECURITY-EDGE.md`. The developer or domain owner ticks them.

## E. Business defaults the owner confirms

- The offer terms printed on the page match what the shop gives.
- Phone number uses English digits.

## F. Steps

1. [ ] `node --test` passes.
2. [ ] `node scripts/validate.mjs` passes.
3. [ ] `node scripts/stage-cloudflare.mjs` builds the upload folder (other servers: `node scripts/stage.mjs`).
4. [ ] Upload only the staged folder, with `npx wrangler deploy --config deploy/cloudflare/wrangler.jsonc --env-file .env.cloudflare` (README, Deploy). Never upload the repo folder.
5. [ ] Headers: Cloudflare applies the prefixed `_headers` from step 3. Other servers: the nginx or Apache snippet with the path prefix.
6. [ ] Run `node scripts/probe.mjs <url>` against the live URL. Every probe passes.
7. [ ] Test with Meta Pixel Helper: events fire on a course click, a book click and a coupon copy. No event on page load beyond PageView.
8. [ ] Open the page with `?utm_source=test&fbclid=test` and check that edgecoursebd.com links carry the params and Rokomari links do not.
9. [ ] Open `#books` and `#courses` deep links.
10. [ ] Log date, commit id, upload time and probe results in `HANDOFF.md`.

Deploy rule: tests pass, the diff is reviewed, the owner says yes, then upload. Agents do not upload.
